Using a key

  -H "Authorization: Bearer sk-sous-…" \
  -H 'Content-Type: application/json' \
  -d '{"model":"…","messages":[{"role":"user","content":"hello"}]}'

Or as the api_key in any OpenAI client with base_url set to {{$.BaseURL}}/v1.
